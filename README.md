# DSP_Ex11
This script explores Finite Impulse Response (FIR) low-pass filter design, demonstrating the relationship between filter order, impulse response, and frequency characteristics.

Technical Details

FIR Filter Design	- Sinc-based low-pass filter implementation

Frequency Response -	Analyzing magnitude and phase characteristics

Filter Order Impact	- Exploring filter performance with different orders

#### Key Filter Design Parameters

    Parameter	            Description	                                Significance
    
    Filter Order (M)	    Number of coefficients	                    Determines filter resolution
    Cutoff Frequency (wc)	Transition between passband and stopband	Defines filter bandwidth
    Sinc Function	        Basis for ideal low-pass filter	            Provides smooth frequency response
